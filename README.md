# Storage Cleanup Tool

> A Python based storage saver.

## Features
- **Instant detection:** immediately searches for temporary files and their contents.
- **Ease of use:** Just run the script and your temporary files will immediately be taken care

## Prerequisites
- Python3
- Windows

### How to use
1. Download project
2. Open terminal in project
3. Run the script: '''bash
    python3 main.py
    '''
